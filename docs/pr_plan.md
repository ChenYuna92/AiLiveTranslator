# PR 提交说明

本项目按功能拆分 PR，每个 PR 只实现或修改一个相对独立的功能。PR 合并后，主分支代码保持可运行状态。

## PR1：初始化项目与基础配置

### 标题

`feat: 初始化项目与基础配置`

### 功能描述

初始化 AI 同声传译助手的基础项目结构，为后续音频采集、语音识别、翻译和字幕展示提供工程框架。

### 实现思路

创建 `backend/`、`frontend/`、`config/`、`utils/` 等目录，补充启动入口、依赖清单、配置文件和环境变量模板。第一阶段主要完成项目骨架和基础运行准备，不夸大为完整功能完成。

### 测试方式

运行：

```powershell
python -m compileall main.py backend frontend utils
```

确认项目基础文件无语法错误。

## PR2：实现实时传译后端链路

### 标题

`feat: 实现实时传译后端链路`

### 功能描述

实现从单向音频流到中文译文输出的后端主链路，包括音频采集、英文语音识别、中文翻译、字幕调度和修正过滤。

### 实现思路

使用 `sounddevice` 采集输入音频，使用 `faster-whisper` 进行英文语音识别，使用腾讯云翻译接口生成中文译文。通过调度器串联各模块，并加入静音过滤、重复过滤和覆盖式修正逻辑。

### 测试方式

1. 配置 `.env` 中的腾讯云翻译密钥。
2. 运行 `python main.py`。
3. 点击“开始传译”，输入英文音频，确认可以生成英文字幕和中文译文。
4. 停顿时确认不会自动出现无对应音频的幻觉字幕。

## PR3：实现中文 GUI 和悬浮双语字幕

### 标题

`feat: 实现中文GUI和悬浮双语字幕`

### 功能描述

实现中文控制窗口和置顶悬浮双语字幕窗口，方便用户在观看网课、会议或技术分享时实时查看翻译结果。

### 实现思路

使用 Tkinter 实现控制窗口和字幕窗口。控制窗口支持选择音频输入源、开始传译、暂停传译和字幕演示。字幕窗口显示英文原文和中文译文，并通过覆盖更新减少修正过程对观看体验的干扰。

### 测试方式

1. 运行 `python main.py`。
2. 确认控制窗口和字幕窗口正常出现。
3. 点击“字幕演示”，确认双语字幕正常更新。
4. 检查 GUI 界面文案除生成的英文字幕外均为中文。
