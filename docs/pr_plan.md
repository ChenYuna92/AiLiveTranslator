# PR拆分建议

本项目建议按以下粒度提交 PR，避免最后一天集中导入代码：

| PR | 标题 | 内容 | 测试方式 |
| --- | --- | --- | --- |
| PR01 | 初始化项目结构与基础配置 | 创建 backend/frontend/config/utils/docs 结构，补充 README、requirements、配置文件 | 检查目录完整，运行 `python -m compileall .` |
| PR02 | 新增音频采集模块 | 实现输入设备枚举和分段音频采集 | 启动程序，确认可选择输入设备 |
| PR03 | 接入语音识别模块 | 使用 faster-whisper 识别英文语音 | 播放英文音频，观察控制台识别结果 |
| PR04 | 接入机器翻译模块 | 使用腾讯云 TMT 翻译英文到中文 | 配置密钥后验证英文句子能输出中文 |
| PR05 | 串联传译主链路 | 串联音频、ASR、翻译、字幕更新 | 点击开始传译，观察字幕窗口更新 |
| PR06 | 增加纠错与去重 | 规范化文本并过滤重复字幕 | 连续播放相似句，确认字幕不重复刷屏 |
| PR07 | 完成中文 GUI 和悬浮字幕 | 控制窗口、字幕窗口、中文界面文案 | 点击字幕演示，确认双语字幕正常 |
| PR08 | 增加语音播报 | 集成 pyttsx3，可配置开启 | 在配置中开启后验证译文播报 |
| PR09 | 联调与文档完善 | 异常处理、README、Demo 录制说明 | 按 README 从零运行项目 |
